## Deployment

### Download Ollama

#### For Windows

Click to [Ollama Windows Download](https://ollama.com/download/windows).

Click to 
```bash
windows + r

ollama run gemma3:1b
```

### Clone the repo
```bash
git clone <repo>

cd <repo>
```

### Create Virtual Environment
```bash
python -m venv venv

venv\Scripts\activate

pip install --no-cache-dir -r requirements.txt
```

### Start the app
```bash
python -m app.main.main
```

### Gets Swagger UI
